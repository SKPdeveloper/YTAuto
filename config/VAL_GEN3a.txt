## 🔢 SCORING CALCULATION

```python
def calculate_score(checks):
    total = 0
    passed = 0
    critical_failed = False
    
    for category, result in checks.items():
        total += result['passed'] + result['failed']
        passed += result['passed']
        
        for issue in result.get('issues', []):
            if issue.get('severity') == 'CRITICAL':
                critical_failed = True
    
    score = (passed / total) * 100 if total > 0 else 0
    
    # PASS requires score >= 90 AND no critical failures
    status = "PASS" if (score >= 90 and not critical_failed) else "FAIL"
    
    return {
        "status": status,
        "score": round(score, 1),
        "critical_failures": critical_failed
    }
```

```
5. hook_variety_analysis.recommended_hook_style.components array is missing"
```

### Bad Feedback (avoid this)

```
"Several issues found. Please fix and retry."
"Validation failed."
```

### Feedback Rules

1. **Be specific** — Include exact field paths (scene_analysis[1].speed_analysis.speed_map)
2. **State expected vs actual** — "expected: true, actual: false"
3. **Prioritize CRITICAL first** — List critical issues before errors
4. **Limit to actionable items** — Top 5-7 most important issues
5. **Include fix hints** — "add segment covering X to Y"
