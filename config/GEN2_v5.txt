## 🎨 gen2_visual_params INTEGRATION (NEW v5.0.0)

**GEN1 v6.0.0 provides structured `gen2_visual_params` per scene. USE THESE — don't guess from prose.**

### Field → Prompt Application

| Field | Use In Image Prompt | Use In Video Prompt |
|-------|--------------------|--------------------|
| `subject_scale` | Camera distance/angle choice | Camera movement intensity |
| `depth_layers` | Foreground/mid/background layering | Parallax motion between layers |
| `dominant_color` | Primary color reference in prose | N/A |
| `contrast_color` | Background/accent color | N/A |
| `texture_focus` | Detail keywords for food surfaces | Texture motion (glistening, dripping) |
| `light_direction` | Light placement in composition | Light shift direction |
| `atmosphere_density` | Haze/fog level (0–1 scale) | Atmospheric motion intensity |

### How to Apply

**subject_scale → camera angle:**
- `MONUMENTAL` / `TOWERING` → low angle, worm's eye
- `MEDIUM` / `HUMAN_SCALE` → eye-level or slight low angle
- `INTIMATE` / `MACRO` → close-up, no scale indicators needed

**atmosphere_density → haze level:**
- `0.0–0.2` → skip atmospheric haze (VIBRANT/PLAYFUL/GOLDEN_WARM/TROPICAL modes)
- `0.3–0.6` → subtle haze, "light atmospheric perspective"
- `0.7–1.0` → full haze, "atmospheric haze and distance fog"

**dominant_color + contrast_color → color prose:**
- Use in place of generic "vibrant food colors": "[dominant_color] tones popping against [contrast_color] background"

**texture_focus → detail keywords:**
- Include directly: "crystallized [texture_focus] surface", "glistening [texture_focus]"

**light_direction → lighting placement:**
- Combine with lighting_master: "[lighting_master.prompt_snippet], light from [light_direction]"

**GEN1 v6.0.0 assigns `scene_tricks[]` + `trick_context` to middle scenes. Tricks define WHAT makes a scene visually interesting. Your prompts MUST reflect them.**

1. **Read** `scene_tricks[]` — array of trick IDs (e.g., `["C06"]`, `["A03", "B12"]`)

### Trick Category → Prompt Impact

| Category | Trick Type | Image Prompt Keywords | Video Prompt Motion |
|----------|-----------|----------------------|-------------------|
| **A: Texture** | MACRO_PORES, CRACKLE, GRAIN | macro detail, surface texture, crystallized/cracked/porous | "surface cracking", "texture shifting" |

## 🏗️ GIGANTISM PROTOCOL (CRITICAL)

### The Problem
Previous outputs looked like toys/miniatures/dioramas. The AI defaults to "cute small" instead of "imposing massive".

### The Solution: Three Mandatory Rules

#### RULE 1: CAMERA ANGLE — WORM'S EYE VIEW

**For Scene 1 (ESTABLISHING) and Scene N/last (LOOP_CLOSE):**

| ❌ NEVER | ✅ ALWAYS |
|----------|----------|
| Look DOWN on building | Look UP at building |
| Bird's eye for hook | Bird's eye only for Scene N-1 |
| Eye-level flat | Low angle, camera near ground |

**Scale Keywords to INJECT:** "Low angle shot looking up", "TOWERING structure", "Imposing scale", "Massive architecture", "Camera near ground level", "Building looms above"

#### RULE 2: ATMOSPHERIC DEPTH

**Large objects have AIR between them and camera. Miniatures do not.**

**Must Include in EVERY exterior prompt (Wide/Medium framing):** "Atmospheric haze", "Distance fog", "Aerial perspective", "Depth separation" — this separates foreground from background and PROVES the object is huge.

#### RULE 3: SCALE INDICATORS

**A wall of chocolate = candy bar. A wall of chocolate with 50 balconies = mansion.**

**Must Include scale reference elements:** "Tiny railings for scale", "Human-scale steps", "Multi-story windows", "Small balconies dotting facade", "Miniature doors showing building height"

#### ⚠️ EXCEPTION: SENSORY SCENES

**Gigantism Protocol does NOT apply to scenes with framing "Extreme Close" or "Close" (STRUCTURAL_DETAIL + LOW energy).** These are macro/texture shots where scale indicators, atmospheric haze, and low angles are counterproductive. Use the SENSORY formula instead.

## 🔄 LOOP ENGINEERING — COMPLEMENTARY MOVEMENT STRATEGY

**Scene N (last) creates seamless loop back to Scene 1 using COMPLEMENTARY movement.**

### The Loop Mechanism

```
Scene 1: Frame A + Movement X → Video 1
Scene N: Frame A + Movement Y (DIFFERENT!) → Video N
         ↓ POST-PRODUCTION: REVERSE Video N
         Result: Reversed Y movement ends at Frame A → seamless loop
         ↓ SEAMLESS LOOP ✅
```

**Key insight:** Scene 1 and Scene N share the SAME first frame (reference image), but have DIFFERENT camera movements.

### Scene N Movement Rules

| Element | Scene 1 | Scene N (LOOP_CLOSE) |
|---------|---------|----------------------|
| First Frame | Frame A | Frame A (IDENTICAL reference) |
| Camera Movement | Movement X | Movement Y (DIFFERENT, complementary) |
| Foreground | Element Z | Element Z (SAME) |
| Lighting | Preset L | Preset L (IDENTICAL) |
| Scale Keywords | TOWERING | TOWERING (SAME) |

**N = last scene number from GEN1 (can be 6, 7, 8, 9, or 10)**

### ⚠️ Scene N Movement Selection

**Read GEN1's Scene N camera_intent — it specifies the COMPLEMENTARY movement.**

| If Scene 1 is | Scene N should be | After Reverse = |
|---------------|-------------------|-----------------|
| Push forward | Rise up / Crane up | Descend into frame |
| Push + Rise | Orbit right | Orbit left into frame |
| Track right | Crane up | Crane down |
| Low angle push | Rise to aerial | Descend from aerial |

### ⛔ Scene N REVERSAL-SAFE MOTION (CRITICAL)

**Scene N video is REVERSED in post. Any motion that looks wrong reversed = BANNED.**

**FORBIDDEN (reversed looks unnatural):** waterfall, falling, cascading down, smoke rising, steam rising, dripping, pouring, fire, flames, walking, running, vehicles moving, birds flying.

**ALLOWED (reversal-safe):** shimmer, glow pulse, light pulsing, atmospheric haze, waves, rippling, rotation, orbiting, light shifting across surface, clouds drifting.

**Self-check:** Before outputting Scene N, verify EVERY motion_element against FORBIDDEN list. Replace with ALLOWED equivalents.

### ⚠️ LOOP VIDEO PROMPT RULES (CRITICAL)

**Scene N video_prompt must be CLEAN for Kling. No meta-instructions!**

```
⛔ BANNED in Scene N video_prompt:
- "matching Scene 1" — Kling doesn't know Scene 1
- "matching opening shot" — Kling doesn't know what that is
- "(REVERSE IN POST)" — instruction for editor, not AI
- "10s" — hardcoded in software
- Any reference to other scenes
- Same movement as Scene 1 (creates mirror effect!)
```

**Scene N video_prompt should:**
1. Describe the COMPLEMENTARY movement from GEN1's camera_intent
2. Use REVERSAL-SAFE motion elements only (replace any Scene 1 elements that are FORBIDDEN)
3. NO references to "matching" or "Scene 1" or post-production
4. Stand alone as independent prompt for Kling

**Example:**

```
Scene 1 video_prompt:
"Low angle camera pushing forward and rising toward TOWERING salmon station, 
clouds drifting behind structure + light bursting through walls + sunlight shifting, 
golden morning atmosphere"

Scene N video_prompt (CORRECT — DIFFERENT movement):
"Camera rising up and ascending to aerial view of TOWERING salmon station, 
clouds drifting behind structure + light shimmer across walls + surface glistening, 
golden morning atmosphere"

Scene N video_prompt (WRONG — same movement):
"Low angle camera pushing forward and rising toward TOWERING salmon station..."

Scene N video_prompt (WRONG — meta instructions):
"...matching Scene 1... (REVERSE IN POST), 10s"
```
