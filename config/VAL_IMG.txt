## 🚫 PHASE 1: GLITCH DETECTION (Instant Reject)

**CRITICAL:** Glitches are TECHNICAL ARTIFACTS of AI generation — NOT creative content.

**Remember:** Glaze City content is INTENTIONALLY surreal. A house made of sushi standing upside-down is CREATIVE, not a glitch. Only reject TRUE rendering failures.

### What IS a Glitch (REJECT)

#### Human Anatomy Errors (REALISTIC HUMANS ONLY)

⚠️ **IMPORTANT:** These rules apply ONLY to **realistic human** depictions. 
Food-based creatures, stylized animals, and fantasy beings are **CREATIVE CONTENT**, not glitches!

| Defect | Description | Example |
|--------|-------------|---------|
| **EXTRA_FINGERS** | More than 5 fingers per hand (realistic human) | Human hand with 6-7 fingers |
| **MISSING_FINGERS** | Fewer than 5 fingers, or fused fingers (realistic human) | Human hand with 3 fingers |
| **EXTRA_LIMBS** | More than 2 arms or 2 legs (realistic human) | Person with 3 arms |
| **FUSED_LIMBS** | Body parts merged incorrectly (realistic human) | Two arms joined into one |
| **FACE_MELT** | Facial features distorted/melted (realistic human) | Human eyes sliding down face |
| **ASYMMETRIC_FACE** | Severely misaligned facial features (realistic human) | One eye much higher than other |
| **TEETH_HORROR** | Too many teeth, wrong placement (realistic human) | Double row of teeth |
| **BODY_PROPORTION_ERROR** | Impossible human proportions (realistic human) | Giant hand on tiny arm |

**⚠️ These are NOT anatomy glitches — DO NOT REJECT:**
- Cookie dog with 3 legs → CREATIVE (stylized food animal)
- Honey bee with cartoon face → CREATIVE (fantasy creature)  
- Gummy bear with exaggerated features → CREATIVE (candy character)
- Bread bird with unusual wings → CREATIVE (food-based animal)
- Chocolate cat with simplified face → CREATIVE (artistic choice)
- Any food-based creature with non-realistic anatomy → CREATIVE

#### Texture/Rendering Corruption

| Defect | Description | Example |
|--------|-------------|---------|
| **TEXTURE_CORRUPTION** | Texture completely breaks | Checkerboard pattern appears randomly |
| **NOISE_PATCHES** | Random colored static/noise | Pink/green noise in corner |
| **COLOR_BLEED** | Colors incorrectly bleeding across boundaries | Red leaking into white area |
| **DUPLICATE_OVERLAY** | Same element rendered twice, overlapping | Two windows in same spot |
| **SHARP_BLUR_MIX** | Inconsistent focus (not artistic) | Random blurry patch in sharp image |
| **JPEG_ARTIFACTS** | Compression blocks, halos | Blocky edges, color banding |
| **WATERMARK_VISIBLE** | AI service watermark visible | Logo or text overlay |
| **GIBBERISH_TEXT** | Text that should be readable but isn't | "WLCME T GLZE CTY" |
| **NON_ENGLISH_TEXT** | Text in wrong language for US market | Cyrillic, Chinese, etc. when not intended |

#### Rendering Failures

| Defect | Description | Example |
|--------|-------------|---------|
| **INCOMPLETE_RENDER** | Part of image not fully generated | Half of object is missing/cut |
| **SEAM_VISIBLE** | Visible seams where AI "stitched" | Line across sky or wall |
| **REPEATED_PATTERN_BUG** | Unnatural exact repetition | Same brick repeated 100x identically |
| **BLACK_VOID** | Unexplained black areas | Black hole in middle of room |
| **WHITE_VOID** | Unexplained white/blown areas | White patch with no source |
| **DUPLICATE_FRAMES** | Multiple separate images in one frame | 2 or more complete pictures stacked/tiled |
| **WRONG_ORIENTATION** | Image rotated 90° sideways | Floor on left/right instead of bottom |

#### ⚠️ CRITICAL: Frame Composition Failures

**DUPLICATE_FRAMES — INSTANT REJECT:**
- Image contains 2+ complete separate pictures
- Usually appears as horizontal split (top/bottom) or vertical split (left/right)
- Each "frame" shows similar but different scene
- Example: Casino interior shown twice with slight variations

**WRONG_ORIENTATION — INSTANT REJECT:**
- Image is rotated 90° (sideways)
- Vertical subjects appear horizontal
- Floor appears on left/right instead of bottom
- Example: Factory scene where floor is on the side

### What is NOT a Glitch (DO NOT REJECT)

| Element | Why It's OK |
|---------|-------------|
| **Food as architecture** | This IS our content — sushi walls, chocolate roofs |
| **Food-based animals/creatures** | Cookie dogs, honey bees, gummy bears = CREATIVE |
| **Stylized animal anatomy** | 3-legged cookie dog, big-eyed candy cat = artistic |
| **Impossible physics** | House floating, inverted buildings = surrealism |
| **Unusual perspectives** | Artistic choice, not a bug |
| **Fantastical elements** | Flying objects, impossible structures = creative |
| **Exaggerated scale** | Giant donut door, tiny furniture = intentional |
| **Surreal combinations** | Waterfall of honey, river of chocolate = on-brand |
| **Stylized lighting** | Dramatic, unusual lighting = artistic |
| **Non-realistic creatures** | Cartoon-style food animals = creative content |

```

```

## 📊 PHASE 2: QUALITY SCORING (Valid Images Only)

Images that pass Phase 1 are scored on these criteria. Each criterion: **0-10 points**.

---

### CRITERION 1: Prompt Adherence (0-10)
*Does the image match what was requested?*

| Score | Description |
|-------|-------------|
| 10 | Perfect match — every element from prompt present and correct |
| 8-9 | Minor deviation — 1-2 small elements differ |
| 6-7 | Noticeable deviation — missing or wrong secondary elements |
| 4-5 | Significant deviation — main subject differs |
| 0-3 | Wrong image — doesn't match prompt intent |

**Check:**
- Correct food material (sushi, chocolate, etc.)
- Correct property type (mansion, penthouse, etc.)
- Correct room/scene (exterior, kitchen, pool, etc.)
- Correct lighting (golden hour, etc.)
- All requested elements present

---

### CRITERION 2: Photorealism (0-10)
*Does it look like a real photograph, not AI-generated?*

| Score | Description |
|-------|-------------|
| 10 | Indistinguishable from real photo — could fool experts |
| 8-9 | Highly realistic — minor tells only on close inspection |
| 6-7 | Good quality — high-end but identifiable as AI |
| 4-5 | Obviously AI — plastic look, uncanny valley |
| 0-3 | Poor quality — cartoonish, game-like, illustration |

**Red Flags (reduce score):**
- Plastic/waxy skin on surfaces
- Over-smoothed textures
- Unnaturally perfect symmetry
- "HDR overdose" look
- Airbrushed/painterly appearance

**For EXTERIOR scenes, also check (NEW v3.0):**
- Atmospheric haze/depth visible (unless VIBRANT mode)
- Foreground/background separation
- Not flat "cutout" look

---

### CRITERION 3: Food Texture Quality (0-10)
*Does the food look appetizing, realistic, and true to material?*

**This is the MOST IMPORTANT criterion for Glaze City.**

| Score | Description |
|-------|-------------|
| 10 | Mouth-watering — glistening, fresh, you want to eat it |
| 8-9 | Excellent — realistic textures, clearly appetizing |
| 6-7 | Good — recognizable and acceptable, minor issues |
| 4-5 | Mediocre — looks fake, plastic-like, unappetizing |
| 0-3 | Poor — unconvincing, repulsive, or unidentifiable |

**What GOOD food texture looks like:**
- **Sushi:** Visible individual rice grains, glistening moist fish, crisp nori
- **Chocolate:** Glossy sheen, rich brown depth, realistic melt patterns
- **Cheese:** Appropriate holes, realistic yellow/orange, proper melt behavior
- **Pasta:** Individual noodle definition, visible sauce texture
- **Bread:** Crust detail, soft interior visible, realistic browning
- **Fruit:** Natural imperfections, realistic skin texture, moisture
- **Honey:** Golden translucency, viscous appearance, light refraction

**Red flags (reduce score, not glitches):**
- Plastic/waxy appearance
- Uniform perfect texture (no natural variation)
- Wrong color saturation
- Food looks dry when should be moist
- Textures too smooth/airbrushed

### CRITERION 4: Composition & Safe Zone (0-10) **(UPDATED v3.0)**
*Professional composition AND Safe Zone compliance*

| Score | Description |
|-------|-------------|
| 10 | Perfect — Architectural Digest level + Safe Zone observed |
| 8-9 | Professional — well-composed + Safe Zone mostly observed |
| 6-7 | Competent — acceptable, minor Safe Zone issues |
| 4-5 | Amateur — poor framing OR Safe Zone violation |
| 0-3 | Bad — unusable composition OR critical elements hidden |

**Check:**
- Rule of thirds applied
- Leading lines present
- Proper headroom/spacing
- No awkward cropping
- Depth and layering

**Safe Zone Validation (MANDATORY for 9:16):**
- [ ] Main subject in **upper 60%** of frame
- [ ] No critical elements in **bottom 20%** (covered by UI)
- [ ] Easter egg NOT in bottom-center zone

**Safe Zone Scoring:**
```
Main subject in upper 60% → +2 points
Critical elements in bottom 20% → -3 points
Easter egg in bottom-center → INSTANT -5 points
```

### CRITERION 8: Scale & Gigantism (0-10) **(NEW v3.0)**
*Does the building/subject feel MASSIVE and life-sized?*

**Only score for EXTERIOR and ESTABLISHING scenes. Mark N/A for INTERIOR/DETAIL.**

| Score | Description |
|-------|-------------|

**Check for EXTERIOR scenes:**

**Scale Indicators by Subject Type:**

| Subject Type | Valid Scale Indicators |

| NATURE | trees, clouds behind, birds |

**Toy Effect Red Flags (reduce score):**
- Tilt-shift blur effect

- No atmospheric depth
- Uniform/flat appearance
- "Cute" or "adorable" feel
- Looks like miniature model

### CRITERION 9: Easter Egg Compliance (0-10)
*If this scene requires an Easter Egg, is it correctly placed?*

**Only score if Easter Egg is required. Otherwise, mark N/A.**

| Score | Description |
|-------|-------------|
| 10 | Perfect — correct object, position, size (5-10%), safe zone |
| 8-9 | Excellent — present and well-placed, minor deviation |
| 6-7 | Good — present but slightly too obvious or too hidden |
| 4-5 | Mediocre — wrong position or wrong size |
| 2-3 | Poor — barely visible or completely wrong |
| 0-1 | Missing — not present when required |
| N/A | Not applicable — scene doesn't require Easter egg |

**Easter Egg Validation Checklist:**
- [ ] Object matches description
- [ ] Size is **5-10%** of frame (findable but not obvious) **(UPDATED v3.0)**
- [ ] Position matches specification
- [ ] Spatial relation correct
- [ ] Doesn't distract from main subject
- [ ] Rewards attentive viewers

**Easter Egg Zone Validation (NEW v3.0):**

| Zone | Status | Action |
|------|--------|--------|
| top-left, top-right | ✅ SAFE | Full score |
| center-left, center-right | ✅ SAFE | Full score |
| center | ✅ SAFE | May be too obvious (-1 point) |
| bottom-left, bottom-right | ⚠️ CAUTION | -2 points (partially covered) |
| **bottom-center** | ❌ BANNED | **-5 points (covered by UI)** |

**If Easter Egg is in bottom-center zone → Maximum score 5/10**

3. Higher "Viral Potential" score wins
